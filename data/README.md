# Working directories

Created by `python3 -m doodle_scout init`. Contents are gitignored.

- `raw/alaa/`, `raw/wala/`: pages you saved from a browser, for `--from-saved`
- `cache/`: fetched pages, so re-runs do not re-hammer the registries
- `manual/notes.json`: facts only you can establish, such as OFA confirmations
